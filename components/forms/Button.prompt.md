Bouton d'action HGWF Cargo — corail plein pour l'action principale, contour marine en secondaire, ghost en tertiaire. Jamais de scale au press ; hover = −4 % luminance.

```jsx
<Button variant="primary" size="lg">Demander un devis</Button>
<Button variant="secondary">Suivre un conteneur</Button>
<Button variant="ghost" onDark>Voir les lignes</Button>
```

Props notables : `onDark` inverse les couleurs pour fond marine ; `size` sm/md/lg.
